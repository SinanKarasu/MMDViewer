# MMD Viewer

MMD Viewer is the small macOS and iPadOS host for the shared `MMDWorkbench`
package. It reads a Mathpix export folder or an individual `.mmd` file, resolves
the neighboring `images/` directory, and can open more than one document window.
TPS WorkShop imports the same package, so rendering and file behavior cannot
drift between the standalone reader and the larger workstation.

Open `MMDViewer.xcodeproj` in Xcode and select either **My Mac** or an iPad
destination. The app requires macOS 26 or iPadOS 26 because it uses WebKit's
native SwiftUI `WebView` and `WebPage` APIs.

The checked-in Xcode project is generated by `generate_project.rb`; the script
will intentionally refuse to overwrite an existing project.
