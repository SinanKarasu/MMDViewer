# MMD Viewer

MMD Viewer is the standalone macOS and iPadOS host for the shared
`MMDWorkbench` package. It reads a Mathpix export folder or an individual `.mmd`
file, resolves the neighboring `images/` directory, and can open more than one
document window.

The application is now its own Git project at:

```text
/Volumes/GitHubDeveloper/Projects/MMDViewer
```

`MMDWorkbench` deliberately remains shared with TPS WorkShop in
`../AtlasConcept/Packages/MMDWorkbench`. Keeping the renderer in one package
prevents the standalone viewer and the larger workstation from drifting.

The app requires macOS 26 or iPadOS 26 because it uses WebKit's native SwiftUI
`WebView` and `WebPage` APIs. The project currently builds with Xcode 27 and
Swift 6.

## Install on this Mac

```bash
cd /Volumes/GitHubDeveloper/Projects/MMDViewer
make install
```

The install rule:

1. performs a signed Release build for macOS;
2. verifies the application signature;
3. installs `MMDViewer.app` in `~/Applications`;
4. moves an existing installation to the Trash before replacement;
5. registers the installed application with Launch Services.

Use another destination when desired:

```bash
make install INSTALL_DIR=/Applications
```

The system Applications directory may require the current account to have
write permission. The default user Applications directory needs no elevation
and is a normal Launch Services application location.

Launch the installed copy with:

```bash
make run
```

## Build in Xcode

Open `MMDViewer.xcodeproj` and select either **My Mac** or an iPad destination.
The checked-in Xcode project is generated by `generate_project.rb`; the script
intentionally refuses to overwrite an existing project.

## `.mmd` integration

The installed application exports `com.sinankarasu.mathpix-markdown`, conforming
to `public.plain-text`, and registers itself as an editor for `.mmd` documents.
It also accepts the `uk.co.mikeosoft.mmd` identifier already present on this
Mac. Files opened from Finder are delivered to the shared reader, with the same
unsaved-change protection used by its Open command.

Rendered Quick Look is the next independent layer. The architectural assessment
and implementation sequence are in [`Docs/QuickLook.md`](Docs/QuickLook.md).
